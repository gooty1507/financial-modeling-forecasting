# Financial Modeling & Forecasting (Python)

A small portfolio of financial modeling scripts — DCF valuation with
sensitivity analysis, and revenue forecasting with trend/seasonality
decomposition — built with Python, pandas, numpy, and matplotlib.

This repo exists to demonstrate the modeling work behind resume lines like
*"Financial Modeling: DCF, ROI, Cost & Profitability Modeling, Forecasting
Models... Scenario & Sensitivity Analysis"* with runnable code instead of
just a bullet point.

## Why these two projects

| Project | Resume connection |
|---|---|
| [`01_dcf_valuation`](./01_dcf_valuation) | DCF / ROI modeling, scenario & sensitivity analysis |
| [`02_revenue_forecasting`](./02_revenue_forecasting) | Forecasting models, trend/seasonality analysis |

Each folder is self-contained: its own script, its own README explaining the
business problem, and a `sample_output/` folder with real output (CSVs and
charts) so a reviewer can see results without cloning and running anything.

## Data

Everything runs against **fully synthetic** data generated by
[`data/generate_data.py`](./data/generate_data.py) — 5 years of annual
financials, a set of valuation assumptions, and 36 months of monthly
revenue with a realistic trend + seasonal pattern. This is not real company
or client data.

## Quickstart

```bash
git clone <your-repo-url>
cd financial-modeling-forecasting
pip install -r requirements.txt

# 1. Generate the synthetic dataset (run once)
python data/generate_data.py

# 2. Run each model
python 01_dcf_valuation/dcf_model.py
python 02_revenue_forecasting/forecast.py
```

Each script also accepts `--data-dir` and `--output-dir` flags — see each
sub-project's README for details.
